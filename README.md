# Sports Lighting Submittal Review Template

This repository provides a concise, reusable review structure for sports-lighting quotations and submittals. It is intended to help owners, contractors and project teams compare proposals using the same project inputs.

## 1. Define the review area

- Identify the playing area and any circulation, spectator or neighboring zones that may be affected by the installation.
- Note known pole locations, mounting constraints and maintenance-access considerations.
- Record the intended operating conditions and the parties responsible for final approvals.

## 2. Request comparable photometric information

A review package should state its calculation area, fixture configuration and aiming assumptions. These details allow a project team to discuss distribution, uniformity and glare control in relation to the actual site rather than relying on a single summary value.

## 3. Coordinate installation and controls

Review cable routing, structural interfaces, aiming access, controls and commissioning at the same time as optical documentation. This keeps practical installation questions visible while options are still being compared.

## 4. Keep the decision record

Capture the selected layout, assumptions and open questions in the project record. A brief written trail makes later coordination clearer for the owner, designer and installer.

## Reference
